# AI Content and Platform Rules

- Default channel language and audience locale: American English (`en-US`), unless explicitly overridden.
- Distinguish internal channel workspaces, external account connection, external channel creation, profile configuration, publishing, and analytics.
- Never claim an external channel/profile was created without official confirmation.
- Use official APIs, least-privilege OAuth, and supported flows.
- If an API does not support an action, provide guided manual setup.
- Never bypass CAPTCHA, platform safeguards, rate limits, monetization review, copyright systems, or disclosure rules.
- Optimize for original, useful content rather than repetitive mass-produced output.
- Track sources for factual claims and rights/provenance for media assets.
- Verify licenses and commercial-use permissions for models, datasets, generated assets, music, footage, and fonts.
- Separate measured data from heuristics; never fabricate trends or analytics.
- Require approval for uncertain or externally visible high-impact actions.
